# Backlog: Portfolio site (Next.js + Tailwind + Sanity)

Last updated 2026-09-30. The site is live on the custom domain (Vercel). The visual design is documented in `docs/design-system.md`.

## Context

A single-page home plus case-study pages, built as a Next.js + Tailwind site backed by Sanity for content that changes over time. It started as a rebuild of a design handoff (`Portfolio-B-Focused`) and has since been redesigned in a neumorphic style (PRs #17, #18).

Decisions still in force:
- **CMS**: Sanity, form-based editing (incl. image upload). Project `eegzn6d8`, dataset `production`.
- **CMS scope**: work/project cards + case studies, experience entries, article links, open-source projects, and the `showExperiments` toggle. Hero, Services, About, Skills, Contact and the legal/consent copy stay hardcoded in `src/lib/constants.ts`: identity copy, not a repeatable list.
- **Routing**: one dynamic `/work/[slug]` route driven by Sanity, not one page file per case study.
- **Studio**: embedded at `/studio` (one deployable). No consent banner, tracking or dark mode there.
- **Linting/formatting**: Biome, not ESLint/Prettier.
- **Types**: generated by `npm run typegen` into `src/lib/sanity/sanity.types.ts` (gitignored, single source of truth for Sanity-shaped types). Regenerate after any schema or query change.
- **Analytics**: Google Tag Manager, loaded only after the visitor accepts the cookie banner. Set `NEXT_PUBLIC_GTM_ID` in Vercel Production only.

## Content ownership

| Content | Source |
|---|---|
| Hero, Services, About, Skills, Contact, nav/logo, footer, cookie + privacy copy | Hardcoded (`lib/constants.ts` + components) |
| Work cards + case studies, incl. screenshots & UX-flow images | Sanity `project` |
| Experience timeline entries | Sanity `experienceEntry` |
| Article/writing collaboration links | Sanity `articleLink` |
| Open-source projects (Experiments section) | Sanity `openSourceProject` |
| Experiments section visibility | Sanity `siteSettings.showExperiments` (singleton) |

Sanity queries revalidate every 60 seconds.
